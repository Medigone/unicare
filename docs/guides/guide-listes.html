Tenir à jour les listes déroulantes

Catégorie d'un client, groupe d'un article, unité, raison de perte d'un devis : ces choix viennent des listes de choix. Ce guide montre comment ajouter une valeur, la renommer, ranger les catégories en dossiers, fusionner un doublon et faire le ménage dans les unités.

La règle à retenir

Une valeur utilisée ne se supprime pas

La colonne Utilisée par dit combien de fiches choisissent chaque valeur. C'est elle qui décide de ce qu'on peut faire.

Inutilisée

Aucune fiche ne la choisit. Elle se renomme, se déplace ou se supprime librement avec la corbeille rouge.

142 clients

Des fiches la choisissent. Elle se renomme partout ou se fusionne dans une autre ; la corbeille est grisée.

Retirée

Pour les unités seulement : elle n'est plus proposée dans les listes, mais reste sur les fiches qui l'ont déjà.

Le nombre est un lien. Cliquez sur « 142 clients » pour ouvrir la liste des clients déjà filtrée sur cette catégorie. Pareil pour les fournisseurs, les articles et les devis perdus.

Pas à pas

Les tâches en détail

1

Ajouter une valeur

Une nouvelle catégorie de clients, une raison de perte qui manque : ajoutée ici, elle apparaît aussitôt dans la liste déroulante des fiches.

Comment faire

  1. Dans Réglages›Listes de choix, choisissez la liste à gauche.
  2. Tapez le nom dans le champ Nouvelle valeur, en haut du tableau.
  3. Pour une liste en dossiers, choisissez le dossier dans le champ dans (la racine par défaut).
  4. Cliquez sur Ajouter ou appuyez sur Entrée. La valeur s'éclaire avec la pastille ajoutée.

Bon à savoir

  • Deux valeurs ne peuvent pas porter le même nom : le message « … » existe déjà. vous le signale.
  • Les onglets Toutes, Utilisées et Inutilisées filtrent le tableau ; la recherche ne tient compte ni des accents ni des majuscules.
2

Renommer ou supprimer

Corriger une faute, harmoniser les noms, retirer une valeur créée par erreur.

Comment faire

  1. Cliquez sur l'icône crayon au bout de la ligne : le nom devient modifiable sur place.
  2. Tapez le nouveau nom, puis Entrée. Échap annule.
  3. Si la valeur est utilisée, confirmez : le nouveau nom s'applique à toutes ses fiches.
  4. Pour supprimer une valeur inutilisée, cliquez sur la corbeille rouge et confirmez.

Bon à savoir

  • Une raison de perte déjà utilisée ne se renomme pas (une limite de l'ERP) : créez-en une nouvelle, ou fusionnez l'ancienne dedans.
  • Survolez une corbeille grisée : une bulle dit pourquoi elle ne se supprime pas.
3

Ranger les catégories en dossiers

Les catégories de clients et de fournisseurs et les groupes d'articles se rangent en arbre : un dossier « Emballages » contient « Flacons », « Bouchons », « Étiquettes ». Sur une fiche, on choisit toujours une valeur, jamais un dossier.

Comment faire

  1. Cliquez sur Nouveau dossier, donnez-lui un nom et choisissez où le ranger (la racine ou un autre dossier).
  2. Pour ajouter une valeur dans un dossier, cliquez sur le + de sa ligne : le champ dans se règle sur lui.
  3. Pour ranger une valeur ou un dossier ailleurs, cliquez sur l'icône Déplacer, choisissez le dossier de destination, puis Déplacer. Le nouveau chemin s'affiche avant de valider, par exemple Matières premières›Étiquettes.
  4. La flèche devant un dossier le déplie ou le replie ; Tout déplier et Tout replier agissent sur tous.

Bon à savoir

  • Déplacer une valeur ne change rien aux fiches qui l'utilisent : seul son rangement change.
  • Un dossier affiche le nombre de valeurs qu'il contient et le total de leurs fiches, par exemple 51 articles au total.
  • Un dossier se supprime seulement vide, et ne se range pas dans un de ses propres sous-dossiers.
  • Une recherche ouvre d'elle-même les dossiers qui contiennent un résultat.
4

Fusionner un doublon

« Pharmacie » et « Pharmacies » désignent la même chose, mais les clients sont répartis sur les deux. La fusion les regroupe dans la valeur gardée, puis supprime l'autre.

Comment faire

  1. Si Unicare repère un doublon, un bandeau bleu le propose : « Pharmacies » ressemble à « Pharmacie ». Cliquez sur Fusionner…. Sinon, cliquez sur l'icône Fusionner de la valeur à faire disparaître.
  2. Dans Fusionner dans, choisissez la valeur à garder.
  3. Vérifiez le résultat : le nombre de fiches après la fusion et les premières fiches reclassées.
  4. Cliquez sur Fusionner dans « … ».

Bon à savoir

  • La fusion ne se défait pas.
  • Unicare repère les valeurs qui ne diffèrent que par les accents, les majuscules ou un pluriel. Ignorer cache la suggestion sur votre ordinateur.
  • On fusionne une valeur dans une autre valeur, jamais un dossier. Les unités ne se fusionnent pas : retirez-les plutôt.
5

Faire le ménage dans les unités

L'ERP arrive avec des dizaines d'unités (gallon, hectare, pied…). Retirer celles qui ne servent pas allège toutes les listes déroulantes du bureau.

Comment faire

  1. Ouvrez la liste Unités. Un bandeau ambre indique combien d'unités proposées ne servent à rien.
  2. Cliquez sur Retirer les … unités inutilisées et confirmez.
  3. Pour une unité en particulier, basculez son interrupteur Proposée.
  4. Basculez Entières pour les unités qui se comptent sans décimale (unité, carton, flacon) ; laissez Décimales pour kg, litre, gramme.

Bon à savoir

  • Sous le nombre de fiches, le détail dit où l'unité sert : 64 articles · 120 prix · 18 lignes de recette.
  • Une unité retirée reste sur les fiches qui l'ont déjà. L'onglet Retirées les montre ; rebasculez Proposée pour en réactiver une.
En cas de blocage

Les messages que vous pouvez voir

« … » existe déjà.

Une valeur porte déjà ce nom, peut-être dans un autre dossier. Cherchez-la : renommez-la ou fusionnez plutôt que d'en créer une seconde.

« … » est utilisée : renommez-la plutôt.

Des fiches la choisissent encore. Renommez-la, ou fusionnez-la dans une autre valeur pour reclasser ses fiches.

Le dossier « … » n'est pas vide.

Déplacez ou supprimez d'abord les valeurs et sous-dossiers qu'il contient, puis supprimez-le.

« … » est rangé dans « … » : il ne peut pas le contenir.

Vous essayez de ranger un dossier dans l'un de ses propres sous-dossiers. Choisissez un dossier situé ailleurs dans l'arbre.

Un dossier ne se fusionne pas.

La fusion ne concerne que les valeurs. Pour regrouper deux dossiers, déplacez le contenu de l'un dans l'autre, puis supprimez celui qui est vide.

« … » est déjà utilisée et ne peut pas être renommée.

Cas des raisons de perte : l'ERP ne les renomme pas une fois utilisées. Créez la nouvelle raison, puis fusionnez l'ancienne dedans.

Cette valeur vient d'être modifiée par ailleurs.

Un collègue a changé la liste pendant que vous l'aviez ouverte. Elle a été rechargée : vérifiez, puis recommencez.
